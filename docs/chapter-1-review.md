# Chapter 1: instructor review

The first implemented chapter is **Classical Systems and Information**, the opening foundation of Part I. This is a review edition, not a claim that all of Part I is complete.

Start at [the chapter overview](https://ashutosh-bhatia.github.io/quantum-machine-learning/site/#classical-information).

## Reading sequence

1. [Finite systems, states and basis labels](https://ashutosh-bhatia.github.io/quantum-machine-learning/site/#classical-states): finite models, ordered basis vectors, binary encodings and unused codes.
2. [Probability distributions and repeated observations](https://ashutosh-bhatia.github.io/quantum-machine-learning/site/#classical-probability): normalization, events, expected counts, finite samples and conditioning.
3. [Deterministic and stochastic operations](https://ashutosh-bhatia.github.io/quantum-machine-learning/site/#classical-operations): conditional transitions, column-stochastic matrices, the derivation of p′ = Mp, normalization and reversibility.
4. [Composing operations](https://ashutosh-bhatia.github.io/quantum-machine-learning/site/#classical-composition): matrix multiplication, temporal order, noncommutation, stochastic closure and sufficient state descriptions.

The four lessons contain approximately 4,500 words of authored explanation, derivations, worked examples and exercise solutions. Four interactive experiments and eight concept checks support the reading. Navigation and solutions remain available without passing a quiz. The check count is saved only in the reader's browser and is explicitly described as a study aid.

## Figures for feedback

Three original, editable SVG figures are marked as drafts in the lessons:

- State labels, basis coordinates and binary encoding.
- Model probabilities versus an explicitly illustrative finite sample.
- Reset and flip in the two temporal orders.

Review mathematical notation, label clarity, and whether each figure helps the explanation. On narrow screens figures can be panned horizontally to retain readable labels. Figure source is generated by `scripts/draw_classical_figures.py`.

## Validation and limits

- The static build validates lesson metadata, quiz placeholders, notebook references and figure references.
- Numerical checks cover operation order, all 36 pairs of the six lab operations, normalization, rectangular matrix composition, invalid inputs, sampling boundaries and binary encoding lengths.
- All 202 authored mathematical expressions pass KaTeX parsing; KaTeX and its fonts are served locally, with its MIT license.
- The notebook executes locally with NumPy 2.5.4 and Matplotlib 3.11.2. It has not been executed in a hosted Colab session.
- Desktop browser checks covered navigation, rendered equations, concept feedback, all four experiments, invalid probability input and preservation of experiment state when jumping within a lesson. The final mobile figure-scroll adjustment has been reviewed in source; a complete mobile device pass remains to be done.
- All three SVG drafts were rendered and visually inspected for clipping and legibility.

The primary source is *Lecture Slides – 1 to 7*, PDF pages 3–13, supported by the introductory lecture transcript. Expanded explanations and figures are newly authored adaptations. Raw source PDFs and classroom transcripts are kept outside the public repository.

## Updating and publishing

Edit lesson HTML in `content/chapters/classical-information/` and metadata in `content/lessons/`. Update the canonical notebook under `notebooks/`, then run `python3 scripts/build.py` and `node scripts/check_classical_math.cjs`. Commit both source and generated website files. Pushing `main` triggers the existing branch-based GitHub Pages deployment.

Later chapters are visibly marked as planned. Earlier short examples are kept in a separately labelled archive, preserving existing links without presenting those drafts as completed new chapters.
