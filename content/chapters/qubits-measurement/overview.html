What do amplitudes predict, what does a measurement record, and what state remains afterwards? This chapter connects the mathematics of Chapter 3 with a precise model of qubit preparation and measurement.

From a state description to an experiment

We start with normalized pure single-qubit states, calculate Born probabilities, distinguish global from relative phase, and work through conditional state updates. The Bloch sphere then provides a state map, and a comparison of two preparation procedures shows why one histogram is not the whole story.

Complex magnitudes, inner products and projectors are the prerequisites. Links and worked calculations revisit these tools where they are used. We use an X-basis measurement mathematically to demonstrate relative phase; its gate implementation and detailed state rotations belong in Chapter 5.

Predict, prepare, measure and explain

Every lesson includes a figure, a reader-controlled activity, two concept checks and worked practice. Treat the activity as an experiment with declared assumptions: choose the preparation, predict its outcomes, run or step the model, then explain the result. Exact probability bars and sampled counts are labelled separately.

The companion notebook uses NumPy for independent calculations and Qiskit for ideal statevector predictions and sampling. Stored statevectors are simulator model data. They do not represent extra information read from a physical qubit.

Practice and explain

Predict first, calculate by hand, then compare your reasoning with the solution.

  1. For ((1+2i)/3,−2/3), calculate Z and X probabilities.
    Hint

    Use (alpha±beta)/sqrt(2) for X amplitudes.

    Worked solution

    Z=(5/9,4/9); X=(5/18,13/18).

  2. Multiply that state by i. Which Z/X probabilities change?
    Hint

    Prove it is one common phase factor.

    Worked solution

    None change. The coordinate amplitudes change, while all the specified measurement probabilities remain unchanged.

  3. Normalize (1−i,2), find Z probabilities and the normalized outcome-0 branch.
    Hint

    Do not discard the component phase prematurely.

    Worked solution

    N=1/sqrt(6), probabilities (1/3,2/3), branch ((1−i)/sqrt(2),0), globally equivalent to |0>.

  4. Write a procedure that estimates Z probabilities without claiming to read both amplitudes.
    Hint

    Specify preparation, one shot, reset and a count denominator.

    Worked solution

    Prepare the same known state for each trial, measure Z once per trial, record classical outcomes, and divide counts by the total. The histogram estimates Z probabilities, not relative phase.

  5. Show why a projector is not an ordinary reversible gate.
    Hint

    Compare P0 with the identity and check its action on |1>.

    Worked solution

    P0 maps |1> to zero and has no full-space inverse; P0†P0=P0≠I. It is used with outcome probabilities and conditional-state rules.

  6. Name assumptions needed for immediate measurement repeatability.
    Hint

    Consider noise, basis changes and intervening gates.

    Worked solution

    An ideal projective measurement, the same measurement basis, retained system, and no intervening evolution or disturbance. Fresh preparation is a different procedure.
