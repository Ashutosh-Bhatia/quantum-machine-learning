Before we discuss a quantum computer, let us ask a simpler question: what do we need to know about a system to describe its state? We can build the language for this question with a switch and a die, and then use it to understand computation.

1. Start with a system we already understand

Consider an on/off switch. If our question is simply which position has been selected, there are two possible answers: off and on. For a die resting on a table, we might ask which face is uppermost. That gives six possible answers. A switch with off, low, medium and high settings gives four.

We call the collection of possible classical state labels the state set, denoted by \(\Sigma\). For these examples,

\[\Sigma_{\mathrm{bit}}=\{0,1\},\quad \Sigma_{\mathrm{die}}=\{1,2,3,4,5,6\},\quad \Sigma_{\mathrm{switch}}=\{\mathrm{off},\mathrm{low},\mathrm{medium},\mathrm{high}\}.\]

Notice the modelling decision we made. A real switch also has a temperature and a physical position; a die has an orientation in space. We have selected the distinctions needed for our question. If the question changes, the state description may need to change too. Describing a switch by its selected setting is enough to record that setting, but it would not be enough to predict the dynamics of a motor connected to it.

We can now see a simple model of computation. A system is in some state; an operation acts on it; the system has an output state. An on/off switch is a small example. A computer memory has many more possible states, but the question is still familiar: what is the state, and how does an operation change it?

Try giving a state set for another familiar device before continuing. State what your labels describe. The important first step is choosing the question, not choosing complicated mathematics.

2. Give each label a coordinate

Suppose our four-setting switch is set to medium. We could write the word “medium” and stop there. Why introduce a vector? Because we want a common mathematical language for definite states, uncertainty about states, and operations on states. A column representation will let us build that language piece by piece.

Choose the coordinate order \((\mathrm{off},\mathrm{low},\mathrm{medium},\mathrm{high})\). Put a 1 in the coordinate corresponding to the selected label and zeros in the other coordinates:

\[e_{\mathrm{off}}=\begin{pmatrix}1\\0\\0\\0\end{pmatrix},\quad e_{\mathrm{low}}=\begin{pmatrix}0\\1\\0\\0\end{pmatrix},\quad e_{\mathrm{medium}}=\begin{pmatrix}0\\0\\1\\0\end{pmatrix},\quad e_{\mathrm{high}}=\begin{pmatrix}0\\0\\0\\1\end{pmatrix}.\]

This is a one-hot representation. The column for medium selects the third position in our declared list. We have not measured a new physical quantity by writing four numbers; we have represented the label in coordinates.

Pause and predict: what if we reverse the list?

Keep the switch at medium, but use the order (high, medium, low, off). Where should the 1 go now?

Work through the change

Medium is the second label in the new list, so its column is \((0,1,0,0)^{\mathsf T}\). The old column was \((0,0,1,0)^{\mathsf T}\). Both describe medium, with different coordinate conventions. Reordering the list does not operate on the switch.

Keep this habit throughout the course: write the order before interpreting a column. Later, the order of qubits in a circuit diagram and the order of symbols in a ket will need the same care.

Does a die have to start at label zero?

No. The physical face label 1 and a programming array position 0 are different things. We can choose the ordered face labels (1,2,3,4,5,6); the column for face 1 is then \((1,0,0,0,0,0)^{\mathsf T}\). A program may store its first entry at array index 0. The mapping between label and position must be stated; it should never be guessed from the number printed on the die.

3. Basis vectors and the ket language

For a finite state set with \(d\) labels, we construct \(d\) standard coordinate vectors. Each has a single 1 in its corresponding coordinate. These form the standard basis: every \(d\)-component vector can be written uniquely as a weighted sum of them.

Let us see what that statement means for the switch. If

\[v=\begin{pmatrix}v_{\mathrm{off}}\\v_{\mathrm{low}}\\v_{\mathrm{medium}}\\v_{\mathrm{high}}\end{pmatrix},\]

then

\[v=v_{\mathrm{off}}e_{\mathrm{off}}+v_{\mathrm{low}}e_{\mathrm{low}}+v_{\mathrm{medium}}e_{\mathrm{medium}}+v_{\mathrm{high}}e_{\mathrm{high}}.\]

Each term contributes to only one coordinate. Adding the terms reconstructs the original column. The coefficients are unique because no other basis vector contributes to that coordinate. This simple observation is why the representation is useful: we can understand a linear operation by understanding its action on the basis columns.

We also write \(|a\rangle\) for the basis column associated with label \(a\), and read it as “ket a.” For a bit, in order (0,1),

\[|0\rangle=\begin{pmatrix}1\\0\end{pmatrix},\qquad |1\rangle=\begin{pmatrix}0\\1\end{pmatrix}.\]

The symbols may look unfamiliar, but here they are names for columns we already understand. Using a ket does not by itself make a description quantum. In the next lesson, a weighted sum will describe classical uncertainty, and the coefficients will be probabilities. When we reach quantum states, the coefficients and the measurement rule will change. We will explain that change explicitly.

4. Four coordinates do not mean four storage bits

How many bits do we need to record the setting of our four-setting switch? Two bits give the strings 00, 01, 10 and 11. We can assign one string to each setting: off ↦ 00, low ↦ 01, medium ↦ 10, high ↦ 11. Every setting has a different code.

Compare this with the one-hot column for medium: it has four entries, but its binary label code has two digits. The coordinate representation and the storage encoding answer different questions. The column provides a basis for calculations; the binary string stores which label was selected.

In general, \(n\) bits provide \(2^n\) different strings: each position has two choices. To encode \(d\) distinct labels with fixed-length strings, we need

\[2^n\ge d,\qquad n_{\min}=\lceil\log_2d\rceil.\]

The ceiling means round up. If logarithms are unfamiliar, ask how many times we must double 1 before reaching at least \(d\). A one-label system needs no information-bearing bit to distinguish alternatives, since there are none.

An extension: when a code has unused strings

Now suppose a different switch has only three settings: off, low and high. One bit is insufficient because it gives only two strings. Two bits still suffice, but now we can use 00, 01 and 10 and leave 11 unused. That unused code does not automatically create another physical setting; an application must decide how to handle it.

A six-state die similarly needs three fixed-length binary digits. Two digits give only four strings; three give eight, leaving two unused. None of this says that the die occupies all its possible faces at once. We have counted labels and assigned codes.

5. Work it through yourself

Reading a column and constructing one yourself are different tasks. Attempt these before opening the hints or worked reasoning.

  1. The lecture's four-setting switch. In order (off, low, medium, high), write the column and fixed binary code for medium using the code defined above. Explain why the column length differs from the code length.
    Hint

    Find medium's position in the coordinate list, then use its assigned binary string. These are separate steps.

    Worked solution

    The column is \((0,0,1,0)^{\mathsf T}\); the code is 10. Four basis coordinates provide a vector representation of the four labels, while two binary digits provide four different strings for storing a label.

  2. Reorder without operating on the device. Rewrite the medium column in order (high, medium, low, off). Does the fixed code 10 change?
    Worked solution

    The column becomes \((0,1,0,0)^{\mathsf T}\). The fixed code remains 10 because we changed the coordinate list, not the label-to-code assignment or the switch setting. A new code assignment would be a separate convention change.

  3. Face label or array position? For face order (1,2,3,4,5,6), write the column for face 3. Which entry would a zero-indexed array select?
    Worked solution

    The column is \((0,0,1,0,0,0)^{\mathsf T}\). Face 3 occupies the third list position, which is array index 2. A numerical face label need not equal its storage index.

  4. Five messages. Find the minimum fixed-length binary storage, give a possible code, and count unused strings.
    Hint

    Count the strings available with two digits and then with three.

    Worked solution

    Three bits suffice: two give only four strings, while three give eight. Use 000, 001, 010, 011 and 100, leaving three strings unused. A one-hot representation would instead have five coordinates.

What have we built?

Choose the state labels, declare their order, and represent each definite label by a basis column. We now have a language for calculations. Next we ask how to use that same language when the system has a definite classical result but we do not know it.
