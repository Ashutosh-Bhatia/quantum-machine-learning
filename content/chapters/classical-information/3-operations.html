A state description tells us what may be present. An operation tells us how that description changes. By placing an operation's response to each definite input into a matrix, we can calculate its response to an uncertain input.

1. Deterministic operations as functions

A deterministic operation on a finite state set is a function \(f:\Sigma\to\Sigma\): for every definite input label, it specifies one definite output label. “Deterministic” describes the operation's response given its input. It does not require the input to be known to us.

For a bit, there are four such functions. There are two choices for \(f(0)\) and, independently, two choices for \(f(1)\), giving \(2\times2=4\) possibilities.

Identity01Keep the input
Flip10Exchange 0 and 1
Reset to 000Output 0 for either input
Reset to 111Output 1 for either input

Define the operation matrix by

\[M_{ij}=\begin{cases}1,&i=f(j),\\0,&i\ne f(j).\end{cases}\]

The column index is the input and the row index is the output. Column \(j\) is the output basis vector produced by input \(|j\rangle\). Therefore \(M|j\rangle=|f(j)\rangle\). This rule is safer than memorizing matrices without knowing which direction their indices represent.

In basis order \((0,1)\), the four matrices are

\[I=\begin{pmatrix}1&0\\0&1\end{pmatrix},\quad X=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad R_0=\begin{pmatrix}1&1\\0&0\end{pmatrix},\quad R_1=\begin{pmatrix}0&0\\1&1\end{pmatrix}.\]

For example, both columns of \(R_0\) are \((1,0)^{\mathsf T}\), because either input is sent to 0. The symbol \(X\) here denotes the classical flip matrix; the same matrix will later act on quantum amplitudes, under a different state model.

2. Stochastic operations: a distribution for each input

An operation may have a random response even when its input is definite. Instead of one output label, associate a conditional distribution with each input:

\[M_{ij}=\Pr(\text{output}=i\mid\text{input}=j).\]

For every fixed input \(j\), these output probabilities must be nonnegative and sum to one. Thus a matrix representing such an operation satisfies

\[M_{ij}\ge0,\qquad \sum_i M_{ij}=1\quad\text{for every column }j.\]

We call this a column-stochastic matrix. Some texts use row probability vectors and row-stochastic matrices. Both conventions can work, but we consistently use columns. Swapping conventions halfway through a calculation changes the meaning of the entries.

Worked example: a random flip

Suppose the operation flips a bit with probability \(\varepsilon\) and leaves it unchanged with probability \(1-\varepsilon\), for either input. Here \(0\le\varepsilon\le1\). Its matrix is

\[B_{\varepsilon}=\begin{pmatrix}1-\varepsilon&\varepsilon\\\varepsilon&1-\varepsilon\end{pmatrix}=(1-\varepsilon)I+\varepsilon X.\]

The first column means input 0 stays 0 with probability \(1-\varepsilon\) and becomes 1 with probability \(\varepsilon\). The second column gives the corresponding probabilities for input 1. At \(\varepsilon=0\) the operation is identity; at \(\varepsilon=1\) it is a definite flip. At \(\varepsilon=1/2\), either definite input produces the uniform output distribution.

Not every stochastic operation treats the inputs symmetrically. The example

\[A=\begin{pmatrix}1&1/2\\0&1/2\end{pmatrix}\]

leaves input 0 unchanged but, given input 1, outputs 0 or 1 with equal probability. Its columns each sum to one even though its rows do not. This is a useful check that we are applying the correct convention.

3. Deriving the update rule \(p'=Mp\)

Let \(p_j\) be the probability of input \(j\), and let \(p'_i\) be the probability of output \(i\). To obtain output \(i\), the input could have been any label \(j\). The probability of each such route is its input probability multiplied by the operation's conditional output probability. Summing these mutually exclusive routes gives the law of total probability:

\[p'_i=\sum_j\Pr(\text{output}=i\mid\text{input}=j)\Pr(\text{input}=j)=\sum_jM_{ij}p_j.\]

This is exactly the definition of the \(i\)-th entry of a matrix–vector product. Therefore,

\[p'=Mp.\]

For a bit, the calculation is explicitly

\[\begin{pmatrix}p'_0\\p'_1\end{pmatrix}=\begin{pmatrix}M_{00}p_0+M_{01}p_1\\M_{10}p_0+M_{11}p_1\end{pmatrix}.\]

Worked example: uncertain input and uncertain operation

Let \(p=(3/4,1/4)^{\mathsf T}\) and \(\varepsilon=1/4\). Then

\[B_{1/4}p=\begin{pmatrix}3/4&1/4\\1/4&3/4\end{pmatrix}\begin{pmatrix}3/4\\1/4\end{pmatrix}=\begin{pmatrix}9/16+1/16\\3/16+3/16\end{pmatrix}=\begin{pmatrix}5/8\\3/8\end{pmatrix}.\]

The second output probability has two contributions: start in 0 and flip, or start in 1 and do not flip. This explanation is the probabilistic meaning of the two terms in the second matrix row. We must not apply an operation only to the most likely input and discard the other possibility.

4. Why the output is still a probability distribution

We should verify that the update rule respects the definition of a distribution. Each output entry is a sum of products of nonnegative numbers, so \(p'_i\ge0\). For the total probability, interchange the finite sums:

\[\begin{aligned}\sum_i p'_i&=\sum_i\sum_jM_{ij}p_j\\&=\sum_jp_j\left(\sum_iM_{ij}\right)\\&=\sum_jp_j=1.\end{aligned}\]

The third line uses the fact that each column of \(M\) sums to one. Thus every valid column-stochastic matrix maps every valid input distribution to another valid distribution. This proof explains why the column condition is the right one; checking a few numerical inputs alone would not establish the general statement.

A deterministic function is a special stochastic operation: each column has one 1 and all other entries 0. It still acts on uncertain input distributions by the same rule. There are therefore two distinct sources of uncertainty: uncertainty in the input preparation and randomness in the operation. They can occur separately or together.

5. Preserving probability does not imply reversibility

The flip has an inverse: applying it twice restores every definite input, so \(X^{-1}=X\). Identity is its own inverse too. Reset-to-zero is different: inputs 0 and 1 both become output 0. Seeing that output does not identify which input occurred.

There cannot be an inverse operation recovering every reset input, because it would have to send the same vector \(|0\rangle\) to two different vectors. The identical columns of \(R_0\) make that loss of input information visible. Reset nevertheless preserves total probability perfectly.

An invertible numerical matrix need not have an inverse that is a physical stochastic operation. For example,

\[B_{1/4}^{-1}=\begin{pmatrix}3/2&-1/2\\-1/2&3/2\end{pmatrix}.\]

This is an algebraic inverse, but it contains negative entries. It cannot act on every probability distribution as a stochastic process. Deterministic bijections, represented by permutation matrices, do have stochastic inverses. This distinction prepares us for the stronger restrictions on closed-system quantum operations later.

6. Practice and worked reasoning

  1. Build a matrix from words. An operation leaves 0 unchanged. Given 1, it outputs 0 with probability 1/3 and 1 with probability 2/3. Construct its matrix and apply it to \(p=(1/4,3/4)^{\mathsf T}\).
    Hint

    Fill the first column from input 0 and the second from input 1. Then multiply by the input probabilities.

    Worked solution

    The matrix is \(M=\begin{pmatrix}1&1/3\\0&2/3\end{pmatrix}\). Therefore \(Mp=(1/4+(1/3)(3/4),\ (2/3)(3/4))^{\mathsf T}=(1/2,1/2)^{\mathsf T}\). Both columns sum to one, and the result is normalized.

  2. Check the convention. Is \(C=\begin{pmatrix}1&0\\1/2&1/2\end{pmatrix}\) a valid operation on our column probability vectors?
    Worked solution

    No. The column sums are 3/2 and 1/2. For example, \(C|0\rangle=(1,1/2)^{\mathsf T}\) is not a normalized distribution. Its rows summing to one does not make it valid under our column convention.

  3. Reversal. Explain why reset cannot be reversed for every unknown input. Is the algebraic inverse of \(B_{1/4}\) a stochastic matrix?
    Worked solution

    Reset maps distinct inputs to the same output, so no function of that output can recover both inputs correctly. The stated inverse of \(B_{1/4}\) reverses the matrix algebra but has negative entries, so it is not a stochastic operation on arbitrary distributions.

What to carry forward

Read an operation column by column: each column describes a definite input. The total-probability rule gives \(p'=Mp\). Normalization preservation, algebraic invertibility, and reversibility by an allowed stochastic operation are separate properties.
