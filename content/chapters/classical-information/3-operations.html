We can now describe a definite bit and uncertainty about a bit. What happens when we apply an operation? Let us begin by writing down what it does to each possible input. The matrix will follow from that rule.

1. Deterministic operations as functions

A deterministic operation on a finite state set is a function \(f:\Sigma\to\Sigma\): for every definite input label, it specifies one definite output label. “Deterministic” describes the operation's response given its input. It does not require the input to be known to us.

How many different deterministic rules can we define for one input bit and one output bit? Try listing them before reading the table. There are two choices for \(f(0)\) and, independently, two choices for \(f(1)\), giving \(2\times2=4\) functions.

All deterministic one-bit functions
Operationf(0)f(1)Meaning
Identity01Keep the input
Flip10Exchange 0 and 1
Reset to 000Output 0 for either input
Reset to 111Output 1 for either input

We could draw four input-to-output mapping diagrams. Instead, let us use the columns we have already built. For each definite input, put its output column in the corresponding position of a matrix. In symbols,

\[M_{ij}=\begin{cases}1,&i=f(j),\\0,&i\ne f(j).\end{cases}\]

The column index is the input and the row index is the output. Column \(j\) is the output basis vector produced by input \(|j\rangle\). Therefore \(M|j\rangle=|f(j)\rangle\). This rule is safer than memorizing matrices without knowing which direction their indices represent.

In basis order \((0,1)\), the four matrices are

\[I=\begin{pmatrix}1&0\\0&1\end{pmatrix},\quad X=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad R_0=\begin{pmatrix}1&1\\0&0\end{pmatrix},\quad R_1=\begin{pmatrix}0&0\\1&1\end{pmatrix}.\]

Test this rule on the two basis inputs yourself. For example, both columns of \(R_0\) are \((1,0)^{\mathsf T}\), because either input is sent to 0. Multiplying by \(|0\rangle\) selects the first column; multiplying by \(|1\rangle\) selects the second. We have translated a rule in words into a calculation.

Remember these four functions. Later we will meet them again in Deutsch’s problem, where the question is about a property of an unknown function. Here we first understand what each function does. The symbol \(X\) denotes the classical flip matrix; the same numerical matrix will later act on quantum amplitudes, under a different state model.

2. An operation can behave probabilistically

Now consider a different rule: if the input is 0, do nothing; if the input is 1, output 0 or 1 with equal probabilities. The input can be definite even though the operation's response is random.

Predict each output before building the matrix

On input 0, the output distribution is \((1,0)^{\mathsf T}\). On input 1, it is \((1/2,1/2)^{\mathsf T}\). Put these in input order (0,1):

\[A=\begin{pmatrix}1&1/2\\0&1/2\end{pmatrix}.\]

Try applying A to both basis columns. The results should reproduce the rule we started with:

\[A|0\rangle=\begin{pmatrix}1\\0\end{pmatrix},\qquad A|1\rangle=\begin{pmatrix}1/2\\1/2\end{pmatrix}.\]

This is why reading a matrix column by column is useful. The first column says what happens given input 0; the second says what happens given input 1. We have not inferred an input probability from an output.

For a general random operation, write

\[M_{ij}=\Pr(\text{output}=i\mid\text{input}=j).\]

For each fixed input j, its possible outputs form a complete probability distribution. Consequently,

\[M_{ij}\ge0,\qquad \sum_iM_{ij}=1\quad\text{for every column }j.\]

This defines a column-stochastic matrix. The rows of A sum to 3/2 and 1/2, which is fine: the columns are the input-conditioned distributions. Texts using row vectors may use a row-stochastic convention. We will consistently use columns.

Build the random rule from simpler actions

We can understand the same operation another way. Choose, with equal probabilities, between doing nothing and resetting to 0. If the input is 0, either choice leaves it 0. If the input is 1, identity leaves it 1 and reset sends it to 0. Thus

\[A=\frac12I+\frac12R_0=\frac12\begin{pmatrix}1&0\\0&1\end{pmatrix}+\frac12\begin{pmatrix}1&1\\0&0\end{pmatrix}=\begin{pmatrix}1&1/2\\0&1/2\end{pmatrix}.\]

The weights describe a random choice between two deterministic actions. We add the weighted matrices because the alternative actions are selected with those probabilities; this is different from performing one after the other.

Compare with a symmetric random flip

Suppose instead that we flip either input with probability \(\varepsilon\) and keep it with probability \(1-\varepsilon\), where \(0\le\varepsilon\le1\). Then

\[B_\varepsilon=(1-\varepsilon)I+\varepsilon X=\begin{pmatrix}1-\varepsilon&\varepsilon\\\varepsilon&1-\varepsilon\end{pmatrix}.\]

This rule treats the two inputs symmetrically; A does not. At \(\varepsilon=0\) we have identity; at 1 a definite flip; at 1/2 either definite input produces a uniform output. Compare A and \(B_{1/2}\) on input 0 to see why they are different operations.

3. What if we do not know the input?

So far we tested definite inputs. Now suppose the preparation is described by p. Should we apply the matrix only to the most likely label? No: each possible input contributes to the output, weighted by its probability.

Let \(p_j\) be the probability of input j. Output i can be reached through any input j. The probability for each route is the input probability times the conditional transition probability. Summing mutually exclusive input routes gives the law of total probability:

\[p'_i=\sum_j\Pr(\text{output}=i\mid\text{input}=j)\Pr(\text{input}=j)=\sum_jM_{ij}p_j.\]

This is precisely the ith entry of a matrix–vector product. Therefore,

\[p'=Mp,\qquad \begin{pmatrix}p'_0\\p'_1\end{pmatrix}=\begin{pmatrix}M_{00}p_0+M_{01}p_1\\M_{10}p_0+M_{11}p_1\end{pmatrix}.\]

Work the lecture's asymmetric operation on an uncertain input

Use the familiar input \(p=(3/4,1/4)^{\mathsf T}\). Predict the two output probabilities, then calculate:

\[Ap=\begin{pmatrix}1&1/2\\0&1/2\end{pmatrix}\begin{pmatrix}3/4\\1/4\end{pmatrix}=\begin{pmatrix}3/4+(1/2)(1/4)\\(1/2)(1/4)\end{pmatrix}=\begin{pmatrix}7/8\\1/8\end{pmatrix}.\]

Why 7/8 for output 0? All the probability already on input 0 stays there, and half the probability on input 1 also arrives at 0. For output 1, only the input-1 route contributes, and only half of it survives. The multiplication records those routes.

As a comparison, \(B_{1/4}\) acting on the same p gives

\[B_{1/4}p=\begin{pmatrix}9/16+1/16\\3/16+3/16\end{pmatrix}=\begin{pmatrix}5/8\\3/8\end{pmatrix}.\]

The different results follow from different transition rules, not a change in the input. Check both rules in the experiment after making your own prediction.

4. Why the output is still a probability distribution

We should verify that the update rule respects the definition of a distribution. Each output entry is a sum of products of nonnegative numbers, so \(p'_i\ge0\). For the total probability, interchange the finite sums:

\[\begin{aligned}\sum_i p'_i&=\sum_i\sum_jM_{ij}p_j\\&=\sum_jp_j\left(\sum_iM_{ij}\right)\\&=\sum_jp_j=1.\end{aligned}\]

The third line uses the fact that each column of \(M\) sums to one. Thus every valid column-stochastic matrix maps every valid input distribution to another valid distribution. This proof explains why the column condition is the right one; checking a few numerical inputs alone would not establish the general statement.

A deterministic function is a special stochastic operation: each column has one 1 and all other entries 0. It still acts on uncertain input distributions by the same rule. There are therefore two distinct sources of uncertainty: uncertainty in the input preparation and randomness in the operation. They can occur separately or together.

5. Preserving probability does not imply reversibility

If both inputs become 0, can we recover the input from that output? This question separates probability preservation from reversibility. The flip can be undone: applying it twice restores every input, so \(X^{-1}=X\). Identity is its own inverse too. Reset-to-zero sends both input labels to the same output, so the output cannot tell us which input occurred.

There cannot be an inverse operation recovering every reset input, because it would have to send the same vector \(|0\rangle\) to two different vectors. The identical columns of \(R_0\) make that loss of input information visible. Reset nevertheless preserves total probability perfectly.

An invertible numerical matrix need not have an inverse that is a physical stochastic operation. For example,

\[B_{1/4}^{-1}=\begin{pmatrix}3/2&-1/2\\-1/2&3/2\end{pmatrix}.\]

This is an algebraic inverse, but it contains negative entries. It cannot act on every probability distribution as a stochastic process. Deterministic bijections, represented by permutation matrices, do have stochastic inverses. This distinction prepares us for the stronger restrictions on closed-system quantum operations later.

6. Work it through yourself

Start by specifying the input-conditioned columns. Then calculate and explain the result; an answer without the interpretation leaves half the task unfinished.

  1. A random choice or a sequence? Explain why choosing identity or reset-to-zero with equal probabilities gives A, but applying identity and then reset-to-zero does not.
    Worked solution

    A random choice gives \((I+R_0)/2=A\), with input 1 producing a half/half distribution. A sequence gives \(R_0I=R_0\), which always outputs 0. Addition with probabilistic weights and temporal composition describe different experiments.

  2. Build a matrix from words. An operation leaves 0 unchanged. Given 1, it outputs 0 with probability 1/3 and 1 with probability 2/3. Construct its matrix and apply it to \(p=(1/4,3/4)^{\mathsf T}\).
    Hint

    Fill the first column from input 0 and the second from input 1. Then multiply by the input probabilities.

    Worked solution

    The matrix is \(M=\begin{pmatrix}1&1/3\\0&2/3\end{pmatrix}\). Therefore \(Mp=(1/4+(1/3)(3/4),\ (2/3)(3/4))^{\mathsf T}=(1/2,1/2)^{\mathsf T}\). Both columns sum to one, and the result is normalized.

  3. Check the convention. Is \(C=\begin{pmatrix}1&0\\1/2&1/2\end{pmatrix}\) a valid operation on our column probability vectors?
    Worked solution

    No. The column sums are 3/2 and 1/2. For example, \(C|0\rangle=(1,1/2)^{\mathsf T}\) is not a normalized distribution. Its rows summing to one does not make it valid under our column convention.

  4. Reversal. Explain why reset cannot be reversed for every unknown input. Is the algebraic inverse of \(B_{1/4}\) a stochastic matrix?
    Worked solution

    Reset maps distinct inputs to the same output, so no function of that output can recover both inputs correctly. The stated inverse of \(B_{1/4}\) reverses the matrix algebra but has negative entries, so it is not a stochastic operation on arbitrary distributions.

What have we learned about an operation?

Begin with its rule on each definite input. Those output columns build the matrix, and total probability gives \(p'=Mp\). Check normalization, then ask separately whether information about the input can be recovered. Next we connect operations in sequence.
