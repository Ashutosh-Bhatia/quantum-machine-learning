Suppose we connect two small devices: the first changes a bit, and the second acts on its output. Can we replace the pair by one operation? Let us follow the intermediate state first, then see why a matrix product describes the whole process.

1. A short matrix-multiplication refresher

We already have state columns and operation matrices. Before combining devices, let us check the multiplication itself. A matrix–vector product takes one row at a time, multiplies its entries by the matching vector entries, and adds the results. For

\[A=\begin{pmatrix}a&b\\c&d\end{pmatrix},\qquad v=\begin{pmatrix}u\\w\end{pmatrix},\qquad Av=\begin{pmatrix}au+bw\\cu+dw\end{pmatrix}.\]

A matrix–matrix product applies the same rule to each column of the right-hand matrix. If

\[B=\begin{pmatrix}e&f\\g&h\end{pmatrix},\]

then

\[AB=\begin{pmatrix}ae+bg&af+bh\\ce+dg&cf+dh\end{pmatrix}.\]

This is not entry-by-entry multiplication. The \((i,j)\) entry is \((AB)_{ij}=\sum_k A_{ik}B_{kj}\). If \(B\) maps input states to intermediate states and \(A\) maps intermediate states to output states, this sum follows every possible intermediate route.

Dimensions are part of the meaning. If \(B\) maps a \(d\)-state input to an \(r\)-state intermediate system and \(A\) maps that to an \(m\)-state output, their dimensions are \(r\times d\) and \(m\times r\). The product \(AB\) is \(m\times d\). Its inner dimensions match because the two operations share the same intermediate labels and order. Our lab uses two-state systems, but the rule is more general.

2. Why the rightmost matrix acts first

Think first about ordinary functions. If we apply f and then g, we write \(g(f(x))\): f acts on the input before g. For our devices, start with a column \(p\). Apply \(A\), obtaining the intermediate state \(p^{(1)}=Ap\). The second device B receives that result:

\[p^{(2)}=Bp^{(1)}=B(Ap)=(BA)p.\]

The last equality uses associativity: compatible matrix multiplication can be regrouped without changing its value. It does not permit us to interchange the factors. The operation closest to the input column acts first. Thus the temporal instruction “A, then B” corresponds to \(BA\), not \(AB\).

For an ordered sequence \(M_1,M_2,\ldots,M_n\),

\[p^{(n)}=M_nM_{n-1}\cdots M_2M_1p.\]

There is no conflict between a process diagram read left to right and a product acting right to left. They are two notations for the same sequence. Write an intermediate state whenever the shorthand becomes confusing.

3. Worked example: reset and flip do not commute

Use the reset-to-zero and flip matrices

\[R_0=\begin{pmatrix}1&1\\0&0\end{pmatrix},\qquad X=\begin{pmatrix}0&1\\1&0\end{pmatrix}.\]

Before looking at a product, predict each stage. If we reset a bit to 0 and then flip it, what must the final label be? If we reverse the devices, what changes? Start with any normalized bit distribution \(p=(p_0,p_1)^{\mathsf T}\). Reset first:

\[R_0p=\begin{pmatrix}p_0+p_1\\0\end{pmatrix}=\begin{pmatrix}1\\0\end{pmatrix}.\]

Flipping that result gives \(X(R_0p)=(0,1)^{\mathsf T}\): the output is certainly 1. The combined matrix confirms this:

\[XR_0=\begin{pmatrix}0&0\\1&1\end{pmatrix}=R_1.\]

Reverse the physical order. Flipping the input first exchanges its probabilities, but resetting afterwards always gives 0:

\[R_0(Xp)=\begin{pmatrix}1\\0\end{pmatrix},\qquad R_0X=\begin{pmatrix}1&1\\0&0\end{pmatrix}=R_0.\]

Consequently \(XR_0\ne R_0X\). These operations do not commute. The difference is not a rounding error or a matter of which input was most probable: the two output distributions are different for every normalized input.

4. Some operations do commute

“Matrix multiplication is not commutative” means we cannot assume \(AB=BA\) for arbitrary matrices. It does not mean no pair ever commutes. Identity commutes with every compatible square matrix. Any matrix commutes with itself. Less trivially, a random-flip matrix \(B_\varepsilon=(1-\varepsilon)I+\varepsilon X\) commutes with \(X\):

\[\begin{aligned}XB_\varepsilon&=(1-\varepsilon)X+\varepsilon X^2=(1-\varepsilon)X+\varepsilon I,\\B_\varepsilon X&=(1-\varepsilon)X+\varepsilon X^2=(1-\varepsilon)X+\varepsilon I.\end{aligned}\]

We used \(X^2=I\), which simply says that two definite bit flips undo one another. Equality of outputs for one chosen input, however, is not enough to prove equality of two operation matrices. They might agree on that input and disagree on another. Equality as linear maps can be checked on an entire basis, since every vector is a linear combination of basis vectors.

5. A composition is still a valid stochastic operation

Let \(A\) and \(B\) be compatible column-stochastic matrices. The combined operation is \(C=BA\), whose entries are

\[C_{ij}=\sum_k B_{ik}A_{kj}.\]

Every entry is nonnegative because each term is a product of nonnegative entries. For a fixed input column \(j\),

\[\begin{aligned}\sum_i C_{ij}&=\sum_i\sum_k B_{ik}A_{kj}\\&=\sum_k A_{kj}\left(\sum_iB_{ik}\right)\\&=\sum_k A_{kj}=1.\end{aligned}\]

The penultimate equality uses the column sum of \(B\); the final equality uses the column sum of \(A\). Therefore \(BA\) is column-stochastic. By applying this argument repeatedly, any finite sequence of valid stochastic operations remains a valid stochastic operation.

The probabilistic interpretation is also useful. The index \(k\) ranges over the intermediate state. The first operation sends input \(j\) to \(k\) with probability \(A_{kj}\), and the second sends \(k\) to output \(i\) with probability \(B_{ik}\). Multiplying the route probabilities and summing over intermediate labels gives the composite transition rule.

A modelling assumption behind the product

The same second-operation rule \(B\) must apply given the intermediate state. If the second device also depends on hidden history, shared randomness, or a changing environment not represented in that state, the state description may need to be enlarged. A convenient matrix product does not eliminate the need for a faithful model.

6. Work it through yourself

Write the input, the intermediate state and the output before simplifying the combined matrix. Then check that both calculation routes agree.

  1. Return to the asymmetric rule. Begin with \(p=(3/4,1/4)^{\mathsf T}\). Apply the previous lesson’s operation A that keeps 0 and randomizes input 1 equally, then apply a definite flip X. Find the intermediate vector, final vector, and combined matrix.
    Hint

    The intermediate result is Ap. The second operation gives X(Ap), so the combined matrix is XA.

    Worked solution

    The intermediate result is \((7/8,1/8)^{\mathsf T}\). Flipping gives \((1/8,7/8)^{\mathsf T}\). Multiplication gives \(XA=\begin{pmatrix}0&1/2\\1&1/2\end{pmatrix}\), which produces the same final vector when applied directly to p. Reversing the devices instead gives \(A(Xp)=(5/8,3/8)^{\mathsf T}\), so this pair also demonstrates why temporal order matters.

  2. One input is not a proof. Identity and flip both leave the uniform distribution \((1/2,1/2)^{\mathsf T}\) unchanged. Are they the same operation?
    Worked solution

    No. On input \(|0\rangle\), identity outputs \(|0\rangle\) while flip outputs \(|1\rangle\). Agreement on one vector is weaker than agreement as operators. Checking their action on both bit basis vectors would distinguish them.

  3. Three operations. A process applies \(A\), then \(B\), then \(C\). Write the combined matrix. If all are column-stochastic, explain why their product is valid.
    Worked solution

    The combined matrix is \(CBA\). The closure proof shows \(BA\) is column-stochastic, and applying it again shows \(C(BA)\) is column-stochastic. Associativity allows the grouping; no factor has been interchanged.

  4. What history must be modelled? A second device behaves differently depending on the original input, even when the same intermediate bit reaches it. Can a single matrix conditioned only on the intermediate bit describe both cases?
    Worked solution

    Not in general. If the same represented intermediate state leads to different conditional output rules depending on omitted history, that bit alone is not a sufficient state description for the proposed composition model. Include the relevant history/environment label or explicitly specify a different operation for each context.

7. Chapter checkpoint and the road to quantum computing

You now have a complete classical calculation pattern: declare the state labels and order; write a probability vector; represent conditional transitions by stochastic columns; compose the matrices in temporal order; interpret the resulting distribution. You should be able to explain each step without relying on a simulation.

  • Represent a definite state and an uncertain description in the same declared basis.
  • Distinguish a probability, an empirical frequency, and a conditional probability.
  • Build an operation from its response to every definite input.
  • Derive \(p'=Mp\) and explain why normalization is preserved.
  • Track intermediate states and show an explicit noncommuting example.

Keep the four one-bit functions and the rule “write the intermediate state” in mind. They will return when we work through Deutsch’s algorithm. Knowing what the classical functions do will help us ask a different question about an unknown function.

Next we develop the complex-number and inner-product language needed for quantum states. Matrix composition will still matter, but the allowed states, operations and measurement rules will change. We will introduce the mathematics where it helps us make that change precisely, while keeping the route toward the classical ML bridge and QML visible.
