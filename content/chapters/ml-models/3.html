A learning algorithm makes choices about both fitting and restraint. More training progress is not automatically better prediction.

The objective can include a penalty

\[J(w,b)=\frac1N\sum_i(wx_i+b-y_i)^2+\lambda\|w\|_2^2.\]

This ridge-style objective penalizes weights but leaves the intercept unpenalized. With this convention the weight gradient adds 2λw. Libraries may use differently scaled penalty parameters, so compare complete formulas before equating their numerical settings.

Larger λ typically shrinks weights more strongly, but useful shrinkage must be chosen using validation data. Regularization does not mean forcing every coefficient toward the same value. Feature scale matters: penalizing coefficients equally can penalize the represented functions unequally when coordinates have different units.

Optimization choices are not the model

Full-batch gradient descent computes a gradient from all training examples. Mini-batches use subsets, producing fluctuating updates and often cheaper steps. Learning rate, initialization, batch size and stopping criterion affect the training path. Early stopping uses a validation criterion to stop before continued fitting harms that criterion.

For the scalar objective J(w)=(w−2)²+λw², the minimizer is w*=2/(1+λ). At λ=0 it is 2; at λ=1 it is 1. The optimum of the penalized objective need not minimize the unpenalized training error.

Bias and variance require careful language

Bias concerns systematic error across hypothetical training datasets; variance concerns sensitivity to which training dataset was observed. They are not simply another name for training loss and test loss. A high-degree interpolating curve can be sensitive to small data changes, but model size alone does not establish its behavior.

We tune model capacity and regularization on validation folds, then evaluate the selected procedure on held-out data. A pipeline refits its scaler inside each fold. The notebook compares polynomial degrees and penalty strengths this way, keeping the test set out of selection. These are habits we will carry into quantum model comparisons.
