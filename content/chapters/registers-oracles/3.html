A classical function can discard information. A unitary operation cannot. The solution is to preserve the input and write the result into a separate target by a reversible update.

1. Keep the input; toggle the target

A Boolean function f maps an n-bit input x to one bit. The direct map |x⟩→|f(x)⟩ cannot generally be unitary: several orthogonal inputs can have the same output, and the input/output dimensions may differ. Instead define

\[(x,y)\longmapsto(x,y\oplus f(x)).\]

The input x is retained. When y=0, the target becomes f(x). When y=1, it becomes the complement of f(x). The definition must cover both target values, not only the initialization used in one experiment.

This full map is bijective even when f is many-to-one. Applying it twice gives y⊕f(x)⊕f(x)=y, restoring the original pair. It therefore permutes computational basis states and extends linearly to a unitary matrix.

For f(x₁x₀)=x₁ AND x₀, only the 110 and 111 basis labels are exchanged. All other labels stay fixed. A Toffoli gate realizes this Boolean oracle when the two input bits are its controls and the target is the output bit. Classical AND as a one-output information-losing map and this three-bit reversible implementation are different operations.

2. Temporary work and uncomputation

A larger function may be calculated through intermediate workspace. Suppose a reversible computation C acts on initialized registers as C|x,0W,0T⟩=|x,g(x),f(x)⟩. A clean output target Y can be updated using a CNOT controlled by T. Then apply C† to the original XWT registers:

\[\sum_x\alpha_x|x,0_W,0_T,y\rangle\longrightarrow\sum_x\alpha_x|x,g(x),f(x),y\rangle\longrightarrow\sum_x\alpha_x|x,g(x),f(x),y\oplus f(x)\rangle\longrightarrow\sum_x\alpha_x|x,0_W,0_T,y\oplus f(x)\rangle.\]

The workspace is restored coherently, without measuring which x occurred. The copy step copies a computational-basis function label through a controlled gate; it does not clone an arbitrary unknown qubit state. On superpositions the full joint calculation is essential.

3. Reset is not an inverse computation

Measuring or resetting correlated workspace generally changes the retained state or removes coherence. It is not a substitute for applying the inverse circuit. A useful implementation must state how its workspace is initialized and whether it is returned clean.

Reversibility also does not imply negligible cost. The function circuit can need many gates and workspace qubits. When an algorithm is analyzed in an oracle-query model, we count calls to a specified interface; practical gate counts and data-access costs still need separate accounting.

Practice and explain

  1. For AND, which three-bit labels are exchanged by the reversible oracle?
    Hint

    Both input bits must be one.

    Worked solution

    110 and 111 are exchanged; all other labels stay fixed.

  2. Show algebraically that the oracle update is its own inverse.
    Hint

    Use a⊕a=0.

    Worked solution

    Two applications give (x,y⊕f(x)⊕f(x))=(x,y).

  3. Why is copying a computed basis label not universal cloning?
    Hint

    Follow a superposed control through CNOT.

    Worked solution

    The output can be entangled across branches; it is not two independent copies of an arbitrary unknown input state.
