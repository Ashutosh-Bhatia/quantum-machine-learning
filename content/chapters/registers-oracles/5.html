An oracle acts on every amplitude through one linear operation. This is useful, but it does not let a single readout reveal the entire truth table.

1. Extend the basis action linearly

\[U_f\left(\sum_x\alpha_x|x\rangle\otimes|0\rangle\right)=\sum_x\alpha_x|x,f(x)\rangle.\]

The amplitudes retain their original coefficients while their basis labels are permuted. With a uniform n-bit input, every αx=1/√(2ⁿ). Measuring both registers in Z returns one x with its associated f(x), with probability |αx|².

For one-bit f(x)=x and plus⊗zero, the output is (00+11)/√2. The registers are entangled. For constant f=0 the output is plus⊗zero; for constant f=1 it is plus⊗one. Coherent function evaluation can entangle registers, but it need not do so.

For two-input parity, the uniform input with target zero becomes

\[\frac{|000\rangle+|011\rangle+|101\rangle+|110\rangle}{2}.\]

There are four possible joint records, each with probability 1/4. The target alone is uniform because half the input labels have parity one. The target histogram discards which input produced each output.

2. What a shot can and cannot return

A simulator can display the complete eight-entry statevector. This is access to the stored model, not data obtainable from a single physical run. After one Z measurement, the record does not include the amplitudes of the other possible branches.

Repeating fresh preparations can estimate distributions, but reconstructing many details may require many measurements. Merely stating that a function was evaluated on a superposition is therefore not a complete speedup argument. A useful quantum algorithm needs a way to transform the desired global property into an accessible outcome distribution.

Nonuniform inputs change the sampling weights. For α|0⟩+β|1⟩ with target zero and identity f, the probability of record 11 is |β|². Coherence is still present in the joint state; calling the input a random classical choice would lose predictions in other bases.

3. Prepare for interference instead of reading everything

Chapter 5 showed how a final mixing gate can make a relative phase visible. Oracle algorithms often arrange that a property of f becomes an amplitude sign pattern, then interfere those signs. The next lesson explains why a minus-state target does this without retaining f(x) as a target basis label.

Compare that with measuring the target immediately. In general, such a measurement selects an output branch and changes the coherent joint state. It is a different procedure from retaining coherence and applying further gates.
