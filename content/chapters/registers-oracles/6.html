The oracle flips its target conditionally. If the target returns to the same physical state, how can the input change? The key is that minus is an eigenstate of the target flip.

1. Follow the phase through the tensor product

\[|-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt2},\qquad X|-\rangle=-|-\rangle.\]

For each basis input x, the oracle applies Xf(x) to the target. Therefore

\[U_f(|x\rangle\otimes|-\rangle)=|x\rangle\otimes(-1)^{f(x)}|-\rangle=(-1)^{f(x)}|x\rangle\otimes|-\rangle.\]

For a superposed input, linearity gives

\[U_f\left(\sum_x\alpha_x|x\rangle\otimes|-\rangle\right)=\left(\sum_x(-1)^{f(x)}\alpha_x|x\rangle\right)\otimes|-\rangle.\]

The target factors out unchanged. The input acquires a sign pattern described by Df=∑x(−1)f(x)|x⟩⟨x|. No classical phase object travels between registers. The equation follows from controlled action, an eigenvalue and linearity. Unlike a target initialized to zero, this target carries no distinguishable basis record of f(x).

2. A common sign versus a relative sign

For plus on one input qubit, the new input is

\[\frac{(-1)^{f(0)}|0\rangle+(-1)^{f(1)}|1\rangle}{\sqrt2}=(-1)^{f(0)}\frac{|0\rangle+(-1)^{f(0)\oplus f(1)}|1\rangle}{\sqrt2}.\]

If f(0)=f(1), both signs agree and the input remains globally equivalent to plus. If they differ, the input is globally equivalent to minus. The two constant functions differ only by a common sign in this preparation; the two nonconstant functions do too.

Before a final H, both cases have Z probabilities (1/2,1/2). H then maps plus to zero and minus to one, up to global phase. This is the building block of Deutsch's algorithm; the next chapter will state the problem, allowed queries and complete comparison with classical strategies.

A plus-state target behaves differently: X|+⟩=|+⟩ has eigenvalue +1, so the oracle leaves the input unchanged. A zero-state target generally entangles with the input. The choice of target preparation is essential, not a cosmetic notation change.

3. More signs need not reveal the whole function

For two-input parity f(x₁x₀)=x₁⊕x₀, uniform input gains signs (+,−,−,+). The input is minus⊗minus, and H⊗H maps it to |11⟩. For AND, the signs are (+,+,+,−); a final H⊗H instead gives four equally likely input labels. That does not identify the entire function from one record.

Phase kickback is a reusable mechanism, not a universal inference rule that any phase pattern becomes a certain bit string. Which property is accessible depends on the input, the function promise and the interference circuit. Query counts describe access to Uf, while its construction and readout costs remain part of a practical analysis.

Practice and explain

  1. For f(0)=f(1)=1, write the output for plus⊗minus.
    Hint

    Both input branches receive −1.

    Worked solution

    The output is −plus⊗minus. It differs from the original joint vector only by global phase.

  2. For f(0)=1,f(1)=0, give input state before and after final H.
    Hint

    The input signs are (−,+).

    Worked solution

    Before H it is −minus; afterwards it is −one. The certain Z record is 1.

  3. What changes if the target is plus instead of minus?
    Hint

    Use the eigenvalue of X on plus.

    Worked solution

    Every controlled branch has eigenvalue +1. The input receives no f-dependent sign and remains unchanged.
