How can a classical function become a coherent quantum operation, and how can its output influence phase rather than appear as a target bit? This chapter builds the register and oracle tools needed for quantum algorithms.

One convention across the chapter

Write |XY⟩, input first and one-bit target last. For two input bits use |x₁x₀ y⟩ with y=q0, x₀=q1 and x₁=q2 in Qiskit. Truth tables are listed in ascending input order. Activities show the complete specified oracle; they do not represent access to an unknown external function.
