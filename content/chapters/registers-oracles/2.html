Many apparent algorithm errors are ordering errors. A reliable calculation starts by writing down what each position means and checking an asymmetric example.

1. Bit significance fixes the amplitude index

For our |x₁x₀ y⟩ ordering, x=2x₁+x₀ and the full column index is

\[k=4x_1+2x_0+y=2x+y.\]

Thus |101⟩ has input x=2, target y=1 and amplitude index 5. The list of basis labels is 000,001,010,011,100,101,110,111. A tensor product of an X column with a Y column follows this same order.

Qiskit labels its statevector entries as |q2 q1 q0⟩, with q0 least significant. The default circuit drawing puts q0 at the top. Consequently the visual top wire is the rightmost factor of this written ket. This is a display convention, not a physical difference between qubits.

For a concrete check, prepare q2=1, q1=0, q0=1. The occupied amplitude must be index 5, not index 3 or 6. A symmetric state such as (000+111)/√2 would fail to expose several reversed-order mistakes.

2. Classical records follow the measurement mapping

If qi is measured into ci for every i in a single three-bit classical register, the displayed string c2c1c0 matches q2q1q0. If instead q2 is measured into c0, q1 into c1, and q0 into c2, the displayed classical label is reversed relative to the quantum label.

For quantum basis state 100, identity measurement wiring gives classical 100. Reversed measurement wiring gives classical 001. The preparation did not change; the locations used to store its results changed. Statevectors refer to quantum basis indices, whereas count keys refer to the classical measurement layout. Multiple classical registers and result interfaces require attention to their own documented formatting.

Changing draw(reverse_bits=True) changes the drawing order, not the gate action or statevector. A physical SWAP gate is different: it actually exchanges subsystem contents. Renaming a subsystem in the mathematical explanation is different again and must be accompanied by a consistent change of factor order.

3. A small convention checklist

  1. Write the ket factor order and identify the least significant bit.
  2. Map every logical role to a physical qubit index.
  3. Check a non-symmetric basis input and a local gate.
  4. Write the quantum-to-classical measurement mapping before interpreting counts.

The chapter notebook makes these checks explicitly before using an oracle. This is preferable to correcting a plot by reversing strings without establishing which mapping caused the discrepancy.

    Hint

    Use k=2x+y.

    Worked solution

    The label is 110 and the index is 6.

  2. Quantum state 100 is measured with q2→c0, q1→c1 and q0→c2. What is the displayed c2c1c0?
    Hint

    Track each bit into its destination.

    Worked solution

    It is 001.

  3. Why is 000+111 a weak test of reversed factor order?
    Hint

    Reverse both strings.

    Worked solution

    They are unchanged under reversal, so some ordering mistakes would remain hidden. Use an asymmetric state such as 100.
