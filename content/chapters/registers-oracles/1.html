Algorithms use several qubits for different purposes. A register is a named group of qubits, helping us organize the state and the operations without changing the underlying quantum mechanics.

1. Name the roles, then specify the state

An input register X contains n qubits and has basis labels x from 0 to 2ⁿ−1. A one-qubit target Y has basis labels y=0,1. A workspace register W, when present, holds temporary computational information. These roles describe the procedure; a register is not a separate kind of quantum object.

\[|\Psi\rangle=\sum_{x=0}^{2^n-1}\sum_{y=0}^{1}\alpha_{x,y}|x\rangle_X\otimes|y\rangle_Y,\qquad\sum_{x,y}|\alpha_{x,y}|^2=1.\]

The full XY column has 2ⁿ⁺¹ complex entries. The input register has dimension 2ⁿ, while the target has dimension two. Do not confuse a number of qubits with the dimension of their state space.

We write |XY⟩ with X on the left and Y on the right. For two input qubits this is |x₁x₀ y⟩. In our notebook y=q0, x₀=q1 and x₁=q2, so Qiskit's |q2 q1 q0⟩ labels match the written order. For one input qubit the mapping reduces to the A=q1, B=q0 convention in Chapter 6.

2. A register need not have its own pure ket

If X is prepared as ∑xαx|x⟩ and Y as |0⟩, their joint input is a product:

\[\left(\sum_x\alpha_x|x\rangle_X\right)\otimes|0\rangle_Y=\sum_x\alpha_x|x,0\rangle.\]

This factorization may cease to hold after an oracle. Naming separate registers does not imply statistical independence or a product quantum state. When they are entangled, calculate with the joint description rather than assigning each register an independent pure ket.

For X=(|00⟩+|10⟩)/√2 and Y=|1⟩, the full state is (|001⟩+|101⟩)/√2. A joint Z measurement returns one of those three-bit records. Reading only X means summing probabilities over the target outcome. Reading Y alone does not reveal every input amplitude.

3. Workspace is part of the state too

A circuit implementation may need additional qubits, often initialized to zero. Once used, they can retain information correlated with the useful output. Omitting them from the written state does not remove those correlations. Later in this chapter we explain how reversing a computation can clean temporary work coherently.

The register notation is useful because it scales: an oracle box can operate on X and Y while its implementation uses W. We must distinguish the promised input/output action from the physical resources needed to realize it.

    Hint

  2. How many basis labels describe four input qubits and two workspace qubits?
    Hint

    Count six qubits in total.

    Worked solution

    The joint state space has 64 basis labels. Its pure-state column has 64 complex entries.

  3. Why must correlated workspace be included in the model?
    Hint

    An unobserved subsystem can still be entangled.

    Worked solution

    Leaving workspace out of the notation does not erase which-branch information or justify a pure-state description for the retained registers.
