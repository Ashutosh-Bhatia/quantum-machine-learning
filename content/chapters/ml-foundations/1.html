Machine learning is a way to construct a rule from examples. Before choosing an algorithm, decide what an example represents, what information is available at prediction time and what outcome matters.

The data–model–objective view

In supervised learning, a dataset contains feature vectors and target values:

\[\mathcal D=\{(x_i,y_i)\}_{i=1}^N,\qquad x_i\in\mathbb R^d,\quad\hat y_i=f_\theta(x_i).\]

A row is an example and a column is a feature. The model family f defines the permitted rules; θ contains parameters learned from training data. Features, parameters and labels have different roles. For a flower example, lengths are features, species is a label, and fitted coefficients are parameters. A useful feature must be available when a new prediction is required.

An image can become a vector by listing pixel intensities in a declared order. A 2×2 grayscale image has four such coordinates. This representation preserves a chosen set of numbers, but does not by itself teach the model which patterns matter. Scaling, missing values and categorical encodings also change the representation seen by an algorithm.

Different tasks ask different questions

Regression predicts a numerical value; classification predicts a category or its probability. Clustering groups examples without supplied class labels. Generative learning models aspects of a data distribution and can generate samples; it is not simply regression with a different output size. Reinforcement learning uses interactions, actions and rewards over time. The labels and evaluation criteria differ across these tasks.

We focus on supervised regression and classification because they give a concrete bridge to variational models and quantum kernels. A list of task names is not a substitute for defining one particular dataset, target and evaluation procedure.

What will change in QML?

The feature representation or model computation may become quantum, but a learning objective and an evaluation protocol remain necessary. More representation dimensions do not automatically mean more useful information or better generalization. Throughout Part B we will keep the data, model, loss, optimizer and evaluation roles separate.

Compare your explanation

Only the third coordinate changes for the bottom-left pixel in row-major order. The vector always has four coordinates. Flattening preserves these pixel values and their declared ordering; identifying a class still requires a target and a learned or specified rule.
