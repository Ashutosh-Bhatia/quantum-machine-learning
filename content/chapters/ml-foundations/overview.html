Chapter challenge

A wearable sensor predicts whether a person is distracted. Several windows come from each person. Specify the target, prediction-time features, a split for deployment to new people, a baseline and a metric when missed positive cases matter.

What a complete answer should explain

Use labelled distraction episodes as targets and only sensor windows available before the prediction deadline. Hold people apart across development and evaluation; fit preprocessing within training folds. Compare against a declared constant or majority baseline. Report recall alongside false positives or precision; choose any threshold with validation data. A random window split would answer a different, easier question.
