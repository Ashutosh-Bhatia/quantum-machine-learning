The purpose of a trained model is usually to predict new examples. Evaluating repeatedly on the examples that influenced its design can give a misleading picture.

Define what unseen means

Training data fits model parameters. Validation data or cross-validation guides model and hyperparameter selection. A held-out test set estimates the performance of the selected procedure. Repeatedly choosing models based on test results makes that test set part of selection.

A random row split is reasonable only when it matches the intended deployment and dependence structure. Measurements from the same person may need a grouped split. Forecasting typically needs a chronological split. Duplicate or closely related examples across partitions can make evaluation unrealistically easy.

Preprocessing can learn too

A scaler learns means and scales from training data. Those values then transform validation, test and future examples. Fitting the scaler on all data leaks information from evaluation examples. Imputation, feature selection and dimension reduction have similar fitted steps. In cross-validation they must be refitted within each training fold; a pipeline makes this arrangement explicit.

Metrics describe different errors

For classification, define true positives, false positives, true negatives and false negatives relative to a declared positive class. Precision is TP/(TP+FP); recall is TP/(TP+FN). If a denominator is zero, the corresponding metric is undefined unless a reporting convention is stated. On a dataset with 90 negatives and 10 positives, always predicting negative has 90% accuracy but zero positive recall.

For regression, compare MSE or MAE against a baseline fitted on training data. Report variation across appropriate splits or repetitions rather than only the most favorable run. Generalization also depends on distribution changes after deployment; a held-out score is not a universal guarantee.

Capacity and regularization

Underfitting occurs when the procedure cannot capture important structure; overfitting occurs when fitting training-specific variation harms new-example prediction. Regularization, more suitable features and sufficient representative data can help, but there is no fixed rule that a larger model must always generalize worse. These considerations also apply to expressive quantum models.

Investigate and explain

Compare thresholds 0.5, 0.3 and 1.0. Which error changes would matter if missing a positive were particularly costly?

Compare your explanation

At 0.5: TP=2, FP=1, TN=2, FN=1. At 0.3: TP=3, FP=2, TN=1, FN=0. Recall rises from 2/3 to 1, while precision falls from 2/3 to 3/5. At 1.0 no positives are predicted: precision is undefined and recall is zero. Thresholds must be selected with validation data and application costs.
