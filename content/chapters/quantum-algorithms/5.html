A quantum advantage claim must name its resource model and success criterion. Deutsch–Jozsa illustrates why changing either can change the conclusion.

1. Exact classical and quantum guarantees

Let N=2ⁿ. A deterministic classical algorithm that must always distinguish constant from balanced needs N/2+1 distinct queries in the worst case. An adversary can answer the same value for the first N/2 queried inputs. Both a constant completion and a balanced completion remain possible. One further matching answer rules out balanced; an opposite answer rules out constant.

\[Q_{\mathrm{classical,exact}}^{\mathrm{worst}}=2^{n-1}+1,\qquad Q_{\mathrm{quantum,ideal}}=1.\]

Two different observed outputs can establish balanced earlier under the promise. The bound is worst-case, not a requirement that every function takes that many queries. For n=2 it is three classical queries versus one coherent call. For n=1 it reduces to Deutsch's two versus one.

2. If a small error is acceptable, the comparison changes

A simple randomized classical procedure samples k inputs independently and uniformly with replacement. If both output values are seen, report balanced. If all values agree, report constant. Constant functions are always classified correctly. For any fixed balanced function, the probability that all k outputs agree is

\[P(\text{error}\mid\text{balanced})=2\left(\frac12\right)^k=2^{1-k},\qquad k\ge1.\]

This is a conditional error probability for the stated sampling procedure, not a posterior probability that f is balanced given particular observations. No prior over functions has been assumed. Taking k≥1+log₂(1/ε) makes the error at most ε, independent of n. A constant number of random classical queries therefore achieves any fixed error tolerance in this query model.

Without replacement, the corresponding error is 2 times the ratio of the binomial coefficients C(N/2,k)/C(N,k), for k≤N/2; it is zero for k>N/2. Sampling distinct inputs can improve the finite-domain behavior. These are example algorithms, not a claim that independent sampling is always optimal.

Consequently, the exponential deterministic exact-query gap should not be presented as an exponential gap over bounded-error randomized classical computation. The success criterion is part of the comparison.

3. Oracle calls are not elapsed time

In the ideal quantum circuit, preparation and the final Hadamard layer use a number of single-qubit gates proportional to n outside the oracle, followed by input readout. Constructing Uf, routing interactions, initializing workspace, mitigating noise and collecting reliable measurements can dominate the physical cost. A truth-table implementation may itself require resources that grow rapidly with n.

The statement “one ideal query suffices” does not mean a noisy device will return the correct answer every time or that one hardware shot is sufficient to validate an implementation. Report measured distributions and uncertainty separately from the ideal mathematical guarantee.

These algorithms teach a useful mechanism: select a property, encode it coherently, and interfere amplitudes into informative readout. They do not establish that a proposed QML model will train faster or generalize better. Later evaluation must include classical baselines, data loading, training and readout costs.

Practice and explain

Predict first, calculate the amplitudes, then check the measurement interpretation.

  1. For n=5, give the worst-case exact deterministic classical query count.
    Hint

    N=32.

    Worked solution

    It is N/2+1=17; the ideal quantum algorithm uses one oracle call.

  2. How many independent classical samples suffice for balanced-case error at most 1/100?
    Hint

    Solve 2^(1−k)≤0.01.

    Worked solution

    k=8 suffices, with error 1/128. This is a sufficient budget for the stated scheme.

  3. A real device returns nonzero output on 90% of balanced-instance runs. Has the ideal theorem changed?
    Hint

    Separate a mathematical model from an implementation.

    Worked solution

    No. The theorem assumes ideal operations and the promise; measured error reflects implementation behavior and must be analyzed statistically.
