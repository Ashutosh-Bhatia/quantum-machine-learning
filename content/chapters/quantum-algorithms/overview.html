How can interference answer a question about a function using fewer exact queries? We build Deutsch and Deutsch–Jozsa from their problem statements, follow every amplitude, then assess what the advantage does and does not mean.

From the question to the evidence

First distinguish a property from a truth table. Then prepare the input and minus target, apply one coherent oracle, and recombine the function-dependent signs. A worked two-input-bit example makes the larger Hadamard sum concrete before its general derivation.

We retain Chapter 7’s order: input X on the left, target Y on the right. One input bit uses |q1 q0⟩; two use |q2 q1 q0⟩. The oracle target is always q0.
