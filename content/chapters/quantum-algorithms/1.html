A quantum algorithm begins with a question, not a circuit. What property is required, what information can a query provide, and what counts as a successful answer?

1. Learn a property rather than the truth table

A Boolean function f takes one input bit x and returns one bit f(x). The four possible truth tables, in order f(0),f(1), are 00,01,10,11. Deutsch's problem asks whether the two values agree. Tables 00 and 11 are constant; 01 and 10 are balanced, meaning exactly half their outputs are zero and half one.

\[s=f(0)\oplus f(1).\]

The required answer is s=0 for constant and s=1 for balanced. We are not asked to identify which of the four functions is present. For this one-bit domain every Boolean function is in one of these two classes, so there are no other cases. For larger domains, the constant-or-balanced restriction becomes a genuine promise.

Classically a query chooses x and receives f(x). Quantumly the available interface is the coherent XOR oracle from Chapter 7: Uf|x,y⟩=|x,y⊕f(x)⟩. We count a use of that entire interface as one oracle query. Its internal gate implementation is not assumed to cost one elementary gate.

2. Why one classical answer is insufficient for certainty

Suppose a classical algorithm queries x=0 and receives 0. Both table 00 and table 01 remain possible. They require different answers. If the response is 1, tables 10 and 11 remain possible, again with different answers. Querying x=1 first gives the same ambiguity.

Two queries suffice: read both values and compute their XOR. Any deterministic classical algorithm correct for every function must use two in the worst case. Random choices do not remove this requirement if the algorithm must always be correct: after only one response there is still an indistinguishable pair of functions with different answers. If error is permitted, a different comparison must be stated explicitly.

The activity exposes the information available after each classical query. Choosing a table specifies the simulator's model; it is not additional information supplied to the algorithm. The compatible tables are those consistent with the responses actually queried.

3. What could one coherent query accomplish?

A superposed query does not return f(0) and f(1) as two classical readout values. Instead, the minus target lets their agreement or disagreement become a relative sign on the input. A final Hadamard converts that sign relation into the one-bit property we asked for.

This is a precise advantage in the stated query model. It does not say that a two-qubit demonstration is faster on a laboratory device than two classical function evaluations. The value here is learning how preparation, coherent access and interference work together.

Practice and explain

Predict first, calculate the amplitudes, then check the measurement interpretation.

  1. After observing f(1)=1, list the compatible truth tables.
    Hint

    Fix the second table entry.

    Worked solution

    They are 01 and 11. They belong to different classes.

  2. Explain why repeating the same classical query does not resolve the ambiguity.
    Hint

    The function is fixed and deterministic.

    Worked solution

    It returns the same output without revealing the other input value.

  3. Is the one-bit Deutsch problem a test of an arbitrary function’s full truth table?
    Hint

    Count the possible answers required.

    Worked solution

    No. It returns one property bit, constant versus balanced, without identifying the two table entries separately.
