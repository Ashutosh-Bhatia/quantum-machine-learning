Now build the circuit around the required property. Keep the input on the left and target on the right, and calculate the state before interpreting any measurement.

1. Prepare the right input and target

Begin in |0⟩X⊗|1⟩Y. Apply H to both qubits:

\[|\psi_0\rangle=|01\rangle,\qquad |\psi_1\rangle=|+\rangle\otimes|-\rangle=\frac{|00\rangle-|01\rangle+|10\rangle-|11\rangle}{2}.\]

The target starts in one so that H produces minus. In the notebook X=q1 and Y=q0. Both Hadamards are state preparation; neither is an oracle query or a measurement.

2. Make one coherent oracle call

\[|\psi_2\rangle=U_f|\psi_1\rangle=\frac{(-1)^{f(0)}|0\rangle+(-1)^{f(1)}|1\rangle}{\sqrt2}\otimes|-\rangle.\]

This follows from X|−⟩=−|−⟩ and the oracle's complete basis action. The target remains minus and factors out. If the function values agree, the input is plus up to a common sign. If they differ, it is minus up to a common sign.

For table 10, the input is (−|0⟩+|1⟩)/√2=−|−⟩. Retaining that minus sign in the calculation prevents confusion between exact vector equality and physical equivalence. It will not change a final probability.

3. Recombine, then read only the property

Apply H to X, leaving Y untouched:

\[|\psi_3\rangle=(-1)^{f(0)}|f(0)\oplus f(1)\rangle_X\otimes|-\rangle_Y.\]

The final Z record on X is 0 for a constant function and 1 for a balanced function, with certainty in the ideal model. Y need not be measured. If it is measured in Z, its result is random and carries no additional distinction between the two function classes.

For f=10 the joint output is −|1⟩⊗|−⟩. The input record is still certainly 1. The constant-one table similarly introduces an overall negative sign while retaining the certain input record 0.

The circuit uses one Uf call, plus preparation and readout gates. No intermediate measurement is inserted. If we measure the input in Z immediately after the oracle, its distribution is uniform in all four cases; we would lose the deterministic property readout that the final H supplies.

The activity steps through the entire joint column. These columns describe the ideal model; they are not information physically read from the qubits between the gates. Reset repeats the preparation, rather than undoing an actual measurement.
