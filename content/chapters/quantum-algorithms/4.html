The n-bit version asks the same kind of property question, but now a promise matters. Begin with four inputs so that every sign and cancellation remains visible.

1. State the promise before using the decision rule

The function f:{0,1}ⁿ→{0,1} is promised to be constant or balanced. Constant means all 2ⁿ outputs agree. Balanced means exactly half are zero and half one. The task is to distinguish these two classes, not verify the promise for an arbitrary function.

For n=2, the promised tables are 0000,1111 and the six four-entry tables containing exactly two ones. AND, table 0001, violates the promise. An algorithm can still be run on it, but its output no longer obeys a guaranteed constant-versus-balanced interpretation.

Start with |0ⁿ⟩|1⟩, apply H to every qubit, call Uf, then apply H only to the input register. The target remains minus. For two input bits, write |x₁x₀ y⟩ with input X=q2q1 and target Y=q0, exactly as in Chapter 7.

2. Work the two-bit example explicitly

Choose f(x₁x₀)=x₀, table 0101. The input sequence, with the common target minus factored out, is

\[|00\rangle\longrightarrow\frac{|00\rangle+|01\rangle+|10\rangle+|11\rangle}{2}\longrightarrow\frac{|00\rangle-|01\rangle+|10\rangle-|11\rangle}{2}\longrightarrow|01\rangle.\]

The four contributions to final 00 sum to (1−1+1−1)/4=0. Those to 01 are all positive and sum to one. The input measurement is therefore nonzero, which means balanced under the promise.

For constant zero, all signs are positive. H⊗H returns 00 certainly; constant one gives its negative, with the same probabilities. For parity table 0110 the final input is 11. Different balanced functions need not give the same nonzero label. In fact all balanced functions on two bits are affine and yield a definite nonzero label here; for more input bits, a balanced function can produce a distribution over several labels.

3. Derive the general amplitude

\[H^{\otimes n}|x\rangle=\frac1{\sqrt{2^n}}\sum_{z\in\{0,1\}^n}(-1)^{x\cdot z}|z\rangle.\]

The dot product x·z is the bitwise product summed modulo two, not an ordinary real-vector inner product. Combining this with the kickback signs gives final input amplitude

\[A(z)=\frac1{2^n}\sum_x(-1)^{f(x)+x\cdot z}.\]

The exponents can be evaluated modulo two. For the all-zero label, x·0ⁿ=0, hence

\[A(0^n)=\frac1{2^n}\sum_x(-1)^{f(x)}=\begin{cases}+1\text{ or }-1,&f\text{ constant},\\0,&f\text{ balanced}.\end{cases}\]

Normalization ensures no other output has nonzero probability in the constant case. In the balanced case, the zero label is impossible. Thus one ideal input measurement distinguishes the promised classes using one oracle call.

For a function with r ones outside the promise, A(0ⁿ)=1−2r/2ⁿ. With two-bit AND, r=1 and P(00)=1/4. Observing zero once would not establish that such an arbitrary function is constant. The editable activity deliberately includes these invalid-promise cases so the limitation can be inspected.

Practice and explain

Predict first, calculate the amplitudes, then check the measurement interpretation.

  1. For parity on two inputs, give the sign pattern and final label.
    Hint

    Factor the signed input into minus⊗minus.

    Worked solution

    The signs are (+,−,−,+), and the final input is 11.

  2. For a three-input-bit function with two ones, calculate P(000). Is the function promised?
    Hint

    Use A(0)=1−2r/8.

    Worked solution

    The amplitude is 1/2 and probability 1/4. The function is neither constant nor balanced.

  3. Why does A(0)=0 imply zero can never be observed ideally?
    Hint

    Apply the Born rule to that output amplitude.

    Worked solution

    Its probability is |A(0)|²=0. Other output amplitudes must carry total probability one.
