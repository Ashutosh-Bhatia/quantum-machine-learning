A model that is linear in one representation can be nonlinear in another. Feature maps change the geometry available to a learning rule.

Lift the representation

\[\phi(x)=(x_1,x_2,x_1^2+x_2^2).\]

For concentric classes, the radius-squared coordinate can make a separating plane possible in feature space even though a line in the original plane cannot separate inner and outer rings. The lifted boundary corresponds to a nonlinear boundary in the original variables.

A feature map need not be learned. It can encode domain knowledge, a polynomial expansion or a fixed transformation. Learned neural representations are another possibility. More features can introduce redundancy and overfitting; a larger coordinate space is not sufficient evidence of improved prediction.

A kernel evaluates a feature-space inner product

\[k(x,z)=\langle\phi(x),\phi(z)\rangle.\]

For two-dimensional vectors, k(x,z)=(xᵀz)² has the explicit map φ(x)=(x₁²,√2 x₁x₂,x₂²). Expanding the dot product verifies the cross term 2x₁x₂z₁z₂. The √2 factor matters: omitting it gives a different kernel.

A valid real kernel yields a symmetric positive-semidefinite Gram matrix K with Kij=k(xi,xj). Positive semidefinite means cᵀKc≥0 for every coefficient vector c. It does not mean every matrix entry must be positive. Symmetry alone is insufficient.

Build a Gram matrix by hand

Use x₁=(1,0), x₂=(0,1), x₃=(1,1) with k(x,z)=(xᵀz)². Every row compares one example with all three examples:

\[K=\begin{pmatrix}1&0&1\\0&1&1\\1&1&4\end{pmatrix}.\]

The diagonal entries are squared feature norms, not probabilities: K₃₃=4 is valid. To see why every inner-product kernel is PSD, write

\[c^TKc=\left\|\sum_i c_i\phi(x_i)\right\|^2\ge0.\]

A numerical eigenvalue check on one matrix is a useful implementation diagnostic; it cannot prove that an arbitrary similarity function defines a kernel for all possible inputs.

Representational power and computational cost

The kernel trick avoids explicitly constructing a potentially large feature vector in algorithms that depend on data only through inner products. It does not automatically avoid the cost of many pairwise evaluations or solving the resulting learning problem.
